# 操作介面用本機網頁，不做桌面應用程式

貼網址扒譜、預覽、編輯鼓譜、輸出的操作介面，做成「Python 本機伺服器（只綁 127.0.0.1）+ 瀏覽器」，用一個啟動檔雙擊開啟。
最難的部分是影片同步播放、WebAudio 即時合成鼓聲、拖曳跳播，瀏覽器原生就做得好；扒譜流程（Demucs、ADTOF、GPU）本來就是 Python，
伺服器直接呼叫即可，不用再橋接一層。只給這台電腦的使用者自己用，不處理多人或其他裝置連線。

## Considered Options

- **pywebview 包成獨立視窗**：UI 跟網頁版完全相同，只是多一個自己的視窗。目前不需要；之後想要「像桌面程式」時再包，成本很低。
- **Electron / Tauri**：要多一套 Node 或 Rust 工具鏈，再去呼叫 Python，對單人本機使用沒有額外好處。
- **PyQt / PySide 原生桌面程式**：影片播放、音訊合成都要重寫，`tools/editor/` 的網頁草稿也用不到。
